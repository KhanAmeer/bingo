BINGO

25 numbers · first to complete the target number of lines wins

You get a room code and a link. Friends open the link (or type the code) on their own phones. Keep this tab open while you play: you are the host.

How it works: every card holds the numbers 1–25 in a random order. The roller draws each number once (Fisher-Yates shuffle) and marks it on every card automatically. Completing a row, column or diagonal counts as one line; the first player to reach the line target shouts BINGO.
